## Componentes Clave del Proyecto de las bolas

### 1. Entorno Visual (Imagen de Fondo)
La atmósfera del juego se establece mediante una imagen de fondo detallada de temática espacial, que incluye edificios de neón y plataformas flotantes.

* **Ubicación del archivo:** `` `Assets/Art/Background.png` ``.

### 2. Lógica de Juego (Script de Movimiento)
El comportamiento de las dos bolas está controlado por un script.

* **Nombre del Script:** `` `PlayerController.cs` ``.
* **Ubicación:** `` `Assets/Scripts/Characters` ``.
* **Función:** Este script detecta la entrada del jugador y aplica fuerzas o velocidad a los GameObjects de las bolas para moverlas a lo largo de la plataforma.
